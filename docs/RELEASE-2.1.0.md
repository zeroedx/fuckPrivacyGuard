# fuckPrivacyGuard v2.1.0

优化了模块界面与隐私保护功能。修复了一些已知问题。

## 本次更新

### 界面

- 底部导航改为五个页面：首页 / 分类 / 诊断 / 设置 / 关于（移除搜索页）
- 分类页改为按系统组件列出，显示组件名称、包名、安装状态与作用域状态，点进组件查看该组件的全部开关
- 视觉改版：底部导航「图标 + 文字」并高亮选中项；组件行带真实应用图标（取不到时用字符徽标）；页面统一大标题；卡片加描边、统一圆角与间距；作用域开关与隐私功能开关分区呈现；浅色 / 深色两套色板按 HyperOS 4 习惯调整（图标全部自绘，未引入新依赖）

### 隐私保护

- 配置同步不再依赖 root：改用 LSPosed 的 RemotePreferences 通道，写入与读取都走框架服务，不再调用 `su -c settings put`
- 从旧版本升级时，首次读取回落一次旧的 `Settings.Global`，之后不再写入该系统设置

### 修复

- 修复已安装系统组件被误显示为「未安装」的问题：按包名精确声明 `<queries>`，并把安装状态区分为「已安装 / 未安装 / 无法确认」，不再把 Package Visibility 查询失败一律当成未安装

## 适配

- 目标环境：Android 17 / HyperOS 4 / arm64-v8a / LSPosed（libxposed API 102）
- 覆盖安装即可升级，签名与包名不变
- 覆盖安装后请在 LSPosed 管理器中重新确认作用域，并重启目标进程
