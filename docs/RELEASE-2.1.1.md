# fuckPrivacyGuard v2.1.1

移除首页、优化关于页，其余功能保持不变。

## 本次更新

### 界面

- 移除首页及其导航入口：应用启动后默认进入「分类」页
- 底部导航保留四项：分类 / 诊断 / 设置 / 关于
- 首页原有的批量操作（全部启用 / 全部停用 / 全部重启）移到「分类」页，功能不变
- 清理首页遗留的图标与文案资源

### 关于页

- 重排信息层级：品牌头（图标 + 模块名 + 版本 chip + 一句话说明）独立成块
- 分组调整：项目 / 版本信息 / 开源与致谢；卡片间距与文字层级统一
- 保留 GitHub 仓库、LSPosed 模块页、问题反馈、检查更新入口
- 保留维护者 zeroedx 与原作者 vivibibi30 / HyperPGuard 的署名与出处致谢
- 保留 GPL-3.0 许可证信息
- 适配浅色 / 深色模式与中英文资源

## 适配

- 目标环境：Android 17 / HyperOS 4 / arm64-v8a / LSPosed（libxposed API 102）
- 包名与签名证书不变，覆盖安装即可升级
- 覆盖安装后请在 LSPosed 管理器中重新确认作用域，并重启目标进程
